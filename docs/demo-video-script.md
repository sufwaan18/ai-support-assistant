# 25-second demo video

This short demo is designed for a quick project introduction.

## Storyboard

- **0–4 seconds:** Show the Tytus.ai name and the line “Reliable answers from trusted support data.”
- **4–9 seconds:** Show the CFPB complaint data being prepared for search.
- **9–16 seconds:** Ask a support question and display a clear answer with complaint sources.
- **16–21 seconds:** Show the flow: question → retrieval → relevant context → grounded response.
- **21–25 seconds:** End on the live interface with “Tytus.ai — AI Support Assistant.”

Keep the real interface visible, use the existing navy and teal theme, and avoid claims or metrics that the project does not verify.
